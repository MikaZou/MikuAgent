# ===== 可选：本地初音未来音色（GPT-SoVITS / GSV-TTS-Lite）=====
#
# 只有把 .env 里的 TTS_ENGINE 设为 sovits 时才需要装这些。
# 体积很大（PyTorch cu128 约 2.6GB），不装也不影响 —— 默认走 edge 在线引擎。
#
# ── 安装步骤 ──────────────────────────────────────────────
# 1) 装 PyTorch（NVIDIA 显卡。无显卡去掉 --index-url 装 CPU 版）
#
#      注意：cu128 的 torch wheel 有 2.6GB，pip 不支持断点续传，
#      国内直连 download.pytorch.org 容易断。建议用项目自带的下载器：
#
#        python tools/fetch_wheel.py ^
#          "https://download.pytorch.org/whl/cu128/torch-2.11.0%2Bcu128-cp310-cp310-win_amd64.whl" ^
#          ".tmp/wheels/torch.whl"
#        python tools/fetch_wheel.py ^
#          "https://download.pytorch.org/whl/cu128/torchaudio-2.11.0%2Bcu128-cp310-cp310-win_amd64.whl" ^
#          ".tmp/wheels/torchaudio.whl"
#        .venv\Scripts\python.exe -m pip install .tmp\wheels\torch.whl .tmp\wheels\torchaudio.whl
#
#      （中断了直接重跑同一条命令即可续传）
#
# 2) 装本文件
#        .venv\Scripts\python.exe -m pip install -r requirements-tts.txt
#
# 3) 准备参考音频（5~10 秒、单人、干声、无伴奏）
#        python tools\prepare_ref_audio.py 你的素材.m4a --out assets\voice\miku_ref.wav --seconds 6
#      GPT-SoVITS 的 prompt 文本是必填的，用它转写出来：
#        （见 README「语音输出」一节）
#
# 4) .env 里配置：
#        TTS_ENGINE=sovits
#        TTS_REF_AUDIO=assets/voice/miku_ref.wav
#        TTS_PROMPT_TEXT=<参考音频的转写文本>
#        TTS_USE_BERT=true        # 中文效果更好；显存吃紧设 false
#
# ── 实机数据（RTX 3050 Ti Laptop 4GB，与开发机同型号）──────
#   - 开 BERT 显存约 2.2GB，关掉约 1.7GB
#   - RTF ≈ 0.78（9.8 秒音频耗时 7.7 秒）
#   - 4GB 显存要和桌宠共享，必须设置 PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True
#     （程序已在启动合成服务时自动设置）
#
